Privacy Policy

Creator OS · last updated 3 October 2026

Creator OS is a personal desktop application for macOS, used only by its developer to plan and review their own YouTube videos.

What it accesses

With the user's permission, Creator OS uses YouTube API Services to read:

  • the user's own channel and video information, and the channel's YouTube Analytics reports (views, watch time, audience retention), with read-only access;
  • public information about channels and videos the user chooses to follow.

Creator OS cannot upload, edit or delete anything on YouTube.

Where data is kept

All data stays on the user's own Mac: in a local database and in backup copies in a folder the user chooses. Sign-in credentials are stored in the macOS Keychain. Creator OS has no server, and it does not send, sell or share any data with anyone.

Data about other channels obtained from the YouTube API is deleted or refreshed within 30 days, as YouTube's policies require.

Third-party terms

Creator OS uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

Access can be revoked at any time on the Google Account third-party connections page. Deleting the app and its data folder removes everything it stored.
